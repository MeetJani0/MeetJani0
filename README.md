### 🧠 Featured Work

**🧙 Harry Potter Knowledge Assistant — RAG System**  
FAISS · Gemini LLM · Streamlit · NLP  
→ End-to-end Retrieval-Augmented Generation system over all seven Harry Potter novels, using dense embeddings, per-book FAISS indexing, and a custom retrieval pipeline to reduce hallucinations.

UNet · Pix2Pix · ResUNet · SwinGAN
