### 🚀 Featured Projects

#### 🧙 Harry Potter Knowledge Assistant — RAG System
**FAISS · Gemini LLM · Streamlit · NLP**  
- End-to-end Retrieval-Augmented Generation system over all seven Harry Potter novels  
- Dense embeddings + per-book FAISS indexing  
- Custom retrieval & filtering pipeline to reduce hallucinations  
🔗 https://github.com/MeetJani0/harry-potter-rag

---

#### 🧠 MRI → CT Translation (Deep Learning)
**UNet · Pix2Pix · ResUNet · SwinGAN**  
- Synthetic CT generation for radiotherapy planning  
- Evaluated using MAE, PSNR, and SSIM  
- Pix2Pix achieved **PSNR 23.8 | SSIM 0.86**

**1D CNN Autoencoder**
